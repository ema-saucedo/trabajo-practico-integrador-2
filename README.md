# Trabajo Práctico Integrador N° II - Frontend

Aplicación frontend desarrollada en React con Vite y Tailwind CSS para el sistema de gestión de Blog Personal con Autenticación.

## Repositorio del Backend
Este proyecto consume la API desarrollada en el Trabajo Práctico Integrador N° I:
- **Backend:** [https://github.com/ema-saucedo/trabajo-practico-integrador-1.git](https://github.com/ema-saucedo/trabajo-practico-integrador-1.git)

---

## Cómo levantar el proyecto

### 1. Clonar e instalar dependencias
```bash
npm install
```

### 2. Iniciar el servidor de desarrollo
```bash
npm run dev
```

La aplicación se ejecutará por defecto en `http://localhost:5173`.
